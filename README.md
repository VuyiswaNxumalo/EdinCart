# EdinCart
# E-Commerce Website

A full-stack online store built with Python (Django) and PostgreSQL.

## Planned Features
- User registration and login
- Product listing, search, and filtering
- Shopping cart and checkout
- Order history
- Admin dashboard
- Payment simulation (test mode)

## Tech Stack
- Back-end: Python, Django
- Database: PostgreSQL
- Front-end: React (to be confirmed)

## Status
In development.
